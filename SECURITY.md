# Security Policy

## Supported Versions

Lych is in early development and has not yet made stable releases. Security
updates are tracked on the `main` branch until the first release.

| Version  | Supported          |
|----------|--------------------|
| `main`   | :white_check_mark: |
| releases | Not yet available  |

## Reporting a Vulnerability

Please report security vulnerabilities by emailing
**mail@rabindrameher.in** instead of opening a public issue.

Please include:

- A description of the vulnerability and the affected component
- Steps to reproduce, or a minimal proof of concept
- The commit or release the issue affects
- Any suggested fix, if you have one

You will receive an acknowledgment within **48 hours**. We ask that you do not
disclose the vulnerability publicly until a fix has been released and announced.

## What to report

Vulnerabilities or security-relevant bugs in the kernel, bootstrap code,
tooling, or CI configuration. For all other bug reports, please use the
[issue templates](https://github.com/rabindra789/lych/issues/new/choose).
